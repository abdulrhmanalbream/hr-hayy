# شؤون الموظفين (Personnel Affairs)

نظام داخلي لإدارة شؤون الموظفين لشركة تطوير الحي: دليل الموظفين، الحضور والانصراف،
طلبات الإجازة مع اعتماد المدير المباشر، لوحة تحكم بإجراءات سريعة، ومسيرات رواتب
أساسية — مبني بنفس تقنية نظام **hdc**: **Next.js 15 (Full-Stack) + MUI + Prisma/PostgreSQL**.

## المستخدمون الثلاثة

| الدور | المنطقة | الصلاحيات |
|---|---|---|
| مسؤول الموارد البشرية (HR_ADMIN) | `/hr` | كل شيء: الموظفون، الأقسام، الإجازات، الرواتب، الإعدادات |
| المدير المباشر (MANAGER) | `/manager` | فريقه فقط — يعتمد/يرفض طلبات إجازة فريقه |
| الموظف (EMPLOYEE) | `/me` | خدمة ذاتية: تسجيل حضور، طلب إجازة، قسائم راتبه |

كل الأدوار تصل أيضاً إلى `/me` للخدمة الذاتية الخاصة بها.

## التشغيل محلياً

```bash
npm install
npm run db:start     # يشغل Postgres محلي (embedded) على المنفذ 5503 — اتركه شغالاً
npm run db:push      # ينشئ الجداول
npm run db:seed      # بيانات تجريبية: أقسام، موظفون، إجازات، رواتب
npm run dev          # http://localhost:3000 (أو المنفذ في NEXT_PUBLIC_APP_URL)
```

**بعد `db:seed`:** حساب دخول واحد فقط (`admin` / `admin1234`، مسؤول موارد بشرية) —
باقي أعضاء الفريق الحقيقيين مُسجّلون كموظفين بلا حساب دخول بعد؛ أنشئ حسابهم من
صفحة كل موظف («إنشاء حساب دخول») عند الحاجة. الرواتب وأرقام الهوية والجوال في
البذر placeholders — عدّلها من صفحة كل موظف.

## المنطق (منع اللخبطة)

- **رصيد الإجازة يُحسب، لا يُخزّن**: `LeaveType.annualDays − مجموع أيام الطلبات المعتمدة لنفس السنة`.
- **قسيمة الراتب لقطة ثابتة** (`Payslip.lineItems` JSON) — تعديل عناصر الراتب لاحقاً
  لا يغيّر قسائم صدرت فعلاً، تماماً مثل عدم رجعية الفواتير الصادرة في hdc.
- **اعتماد الإجازة**: فقط `HR_ADMIN` (أي طلب) أو المدير المباشر الفعلي للموظف
  (`Employee.managerId === session.employeeId`).
- **مسير الرواتب**: أساسي + عناصر مستحقة نشطة − عناصر خصم نشطة − تأمينات اجتماعية
  (نسبة تقريبية من الإعدادات، لا يوجد ربط حقيقي بمنصة التأمينات) − خصم غياب (أيام
  إجازة غير مدفوعة معتمدة خلال الشهر × الراتب اليومي).

## خارج نطاق هذه النسخة (v1)

تطبيق الجوال، الربط الحكومي (GOSI/مدد/قوى/مقيم)، ملف حماية الأجور (WPS)،
إشعارات واتساب/بريد (الإشعارات داخل النظام فقط حالياً)، تخزين R2 (محلي فقط)،
تسجيل دخول موحّد حقيقي مع بوابة SSO (الدخول مستقل حالياً).

## بنية المجلدات

```
prisma/schema.prisma        # الموظفون، الحضور، الإجازات، الرواتب، الوثائق
scripts/dev-db.ts           # Postgres محلي بدون Docker
scripts/seed.ts             # بيانات تجريبية
src/middleware.ts           # حماية المناطق الثلاث حسب الدور (JWT)
src/lib/                    # db, storage (محلي مشفّر), leave/payroll (حسابات), format
src/server/actions/         # كل عمليات الكتابة (Server Actions + Zod)
src/server/queries/         # استعلامات لوحات التحكم
src/app/hr|manager|me/      # المناطق الثلاث
src/app/api/                # auth, files
```
